Transmission 01 / Overview

暗面之后，是更亮的光

Ref: MS-K3-2026
Clearance: Public

这封信来自中国最大的模型之一。Kimi K3 把参数规模推向第一梯队，在主流基准上对标乃至超越国际顶级闭源模型，却选择了一条相反的路——开放权重，免费下载，任君修改。

2026 年 7 月，月之暗面发布 Kimi K3。它支持最高 100 万 token 的上下文窗口，尤其擅长编程、游戏与 3D、知识类任务，并通过 Kimi Code 向开发者开放多种模型档位。

在一个闭源模型收费高昂的时代，K3 以 open-weight 的姿态出现，像一束从月球背面打来的信号——遥远，但任何人都可以接收。
