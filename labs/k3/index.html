Overview

暗面之后，是更亮的光。

Kimi K3 是月之暗面 2026 年 7 月发布的旗舰大模型。它把参数规模推向中国第一梯队，在主流基准上对标乃至超越国际顶级闭源模型，同时坚持开放权重，让每一个人都能下载、修改和部署。

Capabilities

为最难的任务而生。

01
编程
从单文件脚本到跨仓库工程，K3 擅长理解项目结构、自动调用工具、完成长链路开发任务，是 Kimi Code 的核心引擎。
02
游戏与 3D
对 3D 场景、游戏逻辑与空间推理有专门强化，能生成可运行的游戏原型与三维内容代码。
03
知识任务
百万字上下文配合深度思考模式，长文档分析、跨资料推理、复杂问答一次到位。
04
Agent 集群
延续 K2 系列的 Agent 基因，支持长程任务执行与多智能体协作，把目标拆成步骤并逐一落地。
